# ข้อ 58: วิธีคิดแบบคณิตศาสตร์ (Combinatorics & Inclusion-Exclusion)

## สูตรพื้นฐาน (Combinatorics)
จำนวนวิธีเดินจากจุด $A(x_1, y_1)$ ไปจุด $B(x_2, y_2)$ ที่เดินได้แต่ **ขึ้น** หรือ **ขวา** คำนวณได้จาก:

$$N(A \to B) = \binom{\Delta x + \Delta y}{\Delta x} = \frac{(\Delta x + \Delta y)!}{\Delta x! \Delta y!}$$

โดยที่ $\Delta x = x_2 - x_1$ (ระยะทางขวา) และ $\Delta y = y_2 - y_1$ (ระยะทางขึ้น)

## กำหนดพิกัดและจุดห้าม
กำหนดจุดเริ่มต้น $S = (0,0)$ และจุดสิ้นสุด $E = (4,3)$ (ตารางกว้าง 4, สูง 3)
จุดที่ห้ามผ่าน (Obstacles):
- $B_1 = (1,3)$
- $B_2 = (2,1)$
- $B_3 = (3,1)$

## ขั้นที่ 1: คำนวณวิธีทั้งหมดโดยไม่จำกัด
$$N(S \to E) = \binom{4 + 3}{4} = \binom{7}{4} = 35 \text{ วิธี}$$

## ขั้นที่ 2: คำนวณวิธีที่ "ผ่าน" จุดห้าม (Set A, B, C)
ใช้สูตร $N(\text{ผ่าน } P) = N(S \to P) \times N(P \to E)$

**1. ผ่าน $B_1(1,3)$:**
- $N(S \to B_1) = \binom{1+3}{1} = 4$
- $N(B_1 \to E) = \binom{3+0}{3} = 1$
- **รวม =** $4 \times 1 = \mathbf{4}$ **วิธี**

**2. ผ่าน $B_2(2,1)$:**
- $N(S \to B_2) = \binom{2+1}{2} = 3$
- $N(B_2 \to E) = \binom{2+2}{2} = 6$
- **รวม =** $3 \times 6 = \mathbf{18}$ **วิธี**

**3. ผ่าน $B_3(3,1)$:**
- $N(S \to B_3) = \binom{3+1}{3} = 4$
- $N(B_3 \to E) = \binom{1+2}{1} = 3$
- **รวม =** $4 \times 3 = \mathbf{12}$ **วิธี**

## ขั้นที่ 3: ลบการซ้ำซ้อน (Inclusion-Exclusion Principle)
ต้องดูว่ามีการเดินผ่านจุดห้ามหลายจุดซ้อนกันหรือไม่:
- **$B_1 \to B_2$ หรือ $B_1 \to B_3$:** เป็นไปไม่ได้ (เพราะ $y$ ลดลงจาก 3 ไป 1) = $0$
- **$B_2 \to B_3$:** เป็นไปได้!
  - $N(S \to B_2) = 3$
  - $N(B_2 \to B_3) = \binom{1+0}{1} = 1$
  - $N(B_3 \to E) = 3$
  - **รวมการซ้ำซ้อน =** $3 \times 1 \times 3 = \mathbf{9}$ **วิธี**

## ขั้นที่ 4: คำนวณคำตอบสุดท้าย
$$\text{วิธีที่ถูกต้อง} = \text{ทั้งหมด} - (N(B_1) + N(B_2) + N(B_3)) + N(B_2 \cap B_3)$$

$$\text{วิธีที่ถูกต้อง} = 35 - (4 + 18 + 12) + 9$$
$$\text{วิธีที่ถูกต้อง} = 35 - 34 + 9 = \mathbf{10} \text{ วิธี}$$
