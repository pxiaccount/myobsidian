# 12. ฮายเวอร์โบลา: จุดศูนย์กลางและเส้นตรงผ่านจุดกำเนิด

โจทย์ (ภาษาไทย):
- ให้สมการฮายเวอร์บลา
  $$25x^2 - 16y^2 - 150x - 64y - 239 = 0$$
- และเส้นตรง L ผ่านจุดกำเนิด (0, 0)
- จงหาค่าของเส้นตรง L ที่ตอบโจทย์

## วิธีหาจุดศูนย์กลางและรูปแบบมาตรฐาน
1. เรียงกลุ่มพหุนาม: 
   $$25x^2 - 150x - 16y^2 - 64y - 239 = 0$$
2. จัดรูปจุด: ปิดกรอบกำกับกำหนดให้สมบูรณ์กำลังสอง
   
   - สำหรับ x:
     $$25(x^2 - 6x) = 25\big((x-3)^2 - 9\big) = 25(x-3)^2 - 225$$
   - สำหรับ y:
     $$-16(y^2 + 4y) = -16\big((y+2)^2 - 4\big) = -16(y+2)^2 + 64$$
   
   ดังนั้น
   $$25(x-3)^2 - 16(y+2)^2 - 400 = 0$$
3. เขียนในรูปมาตรฐาน
   $$\frac{(x-3)^2}{16} - \frac{(y+2)^2}{25} = 1$$
   ซึ่งมีศูนย์กลางที่ 
   
   \(h, k\) = (3, -2)\;
   
## เส้นตรง L ผ่านจุดกำเนิด
- จุดศูนย์กลางของฮายเวอร์บลาอยู่ที่ (3, -2)
- เส้นตรงที่ผ่านจุดกำเนิด (0, 0) และผ่านจุดศูนย์กลางมีความชัน
  
  \(m = \dfrac{k - 0}{h - 0} = \dfrac{-2 - 0}{3 - 0} = -\dfrac{2}{3}\)
-	herefore เส้นตรง L มีสมการ
  
  $$y = -\frac{2}{3}x$$

## คำตอบและแมชกับตัวเลือก
- ตอบ: ก. y = -\frac{2}{3}x
- ข้ออื่นที่ให้มาไม่ผ่านจุดกำเนิดหรือไม่ผ่านจุดศูนย์กลาง
