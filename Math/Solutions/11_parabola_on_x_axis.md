# 11. สมการพาราโบลา: จุดยอดบนแกน X

- ก. x^2 - 6x + 2y + 9 = 0
  - 2y = -x^2 + 6x - 9
  - = -(x^2 - 6x + 9)
  - = -(x - 3)^2
  - y = -1/2 (x - 3)^2
  - จุดยอด (h, k) = (3, 0) → บนแกน X

- ข. y^2 - 6y + 2x + 9 = 0
  - 2x = -y^2 + 6y - 9
  - = -(y^2 - 6y + 9)
  - = -(y - 3)^2
  - x = -1/2 (y - 3)^2
  - จุดยอด (0, 3) → ไม่บนแกน X

- ค. y^2 - 6y - 2x + 9 = 0
  - -2x = -y^2 + 6y - 9
  - x = 1/2 (y^2 - 6y + 9)
  - = 1/2 (y - 3)^2
  - จุดยอด (0, 3) → ไม่บนแกน X

- ง. x^2 - 6x + 2y - 9 = 0
  - 2y = -x^2 + 6x + 9
  - y = -1/2 (x^2 - 6x) + 9/2
  - เขียนเป็น y = a(x - h)^2 + k:
  - a = -1/2, h = 3, k = 9
  - จุดยอด (3, 9) → ไม่บนแกน X

- จ. x^2 - 6x - 2y + 9 = 0
  - -2y = -x^2 + 6x - 9
  - y = 1/2 x^2 - 3x + 9/2
  - จุดยอด (3, 0)
  - บนแกน X

สรุปคำตอบ: ก และ จ มีจุดยอดบนแกน X (เมื่อ y = 0)
