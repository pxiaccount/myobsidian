# ข้อ 57 — จอมโจร 5 คน

## กำหนดให้

| คน  | ชื่อ           |     |
| --- | -------------- | --- |
| $G$ | จอมโจรกาลเวลา  |     |
| $R$ | จอมโจรรัตติกาล |     |
| $D$ | จอมโจรดีลักซ์  |     |
| $A$ | จอมโจรอัคนีเงา |     |
| $N$ | จอมโจรเนตรทมิฬ |     |

**กฎ:** พูดจริง $2$ คน, พูดโกหก $3$ คน

**บทบาท:** ผู้บงการ $1$ คน (โกหก), นักฆ่า $1$ คน (จริง), ผู้บริสุทธิ์ $3$ คน (จริง $1$ + โกหก $2$)

## คำพูด

| คน | คำพูด |
|---|---|
| $G$ | 1) ผู้บงการคือ $D$ หรือ $A$ $\quad$ 2) $N$ พูดจริง |
| $R$ | 1) นักฆ่าไม่ใช่ $D$ $\quad$ 2) $G$ พูดจริง |
| $D$ | ถ้า $R$ โกหก แล้ว $N$ เป็นนักฆ่า |
| $A$ | ผู้บงการพูดจริง หรือ $R$ เป็นผู้บงการ |
| $N$ | $A$ พูดจริง หรือ $D$ เป็นผู้บงการ |

## การวิเคราะห์

### ขั้นที่ 1: พิจารณา $G$

**สมมติ $G$ พูดจริง ($G = T$):**
- $R$ พูดว่า "$G$ พูดจริง" → จริง
- ถ้า $R = T$ → ทั้ง $G, R$ เป็น $T$ → $D, A, N$ เป็น $L$
  - $D = L$ → "$R = L \Rightarrow N = \text{นักฆ่า}$" เป็นเท็จ → $R = L$ และ $N \neq \text{นักฆ่า}$
  - แต่ $R = T$ → ขัดแย้ง ❌
- ถ้า $R = L$ → คำพูดข้อ 1 ของ $R$ เป็นเท็จ → นักฆ่า $= D$
  - $D = \text{นักฆ่า} = T$ → "$R = T \lor N = \text{นักฆ่า}$" → $N = \text{นักฆ่า}$
  - แต่ $D = \text{นักฆ่า}$ → $N \neq \text{นักฆ่า}$ → ขัดแย้ง ❌

**ดังนั้น $G$ ต้องโกหก ($G = L$)**

### ขั้นที่ 2: จาก $G = L$

- $R$ พูดว่า "$G$ พูดจริง" → **เท็จ** → $R$ ต้องเป็น $L$ (เพราะถ้า $R = T$ คำพูดต้องจริงทั้งคู่)

**ได้ $G = L, R = L$** → เหลือ $T$ อีก $2$ คน จาก $\{D, A, N\}$

### ขั้นที่ 3: พิจารณา $D$

คำพูดของ $D$: "$R = L \Rightarrow N = \text{นักฆ่า}$" = "$R = T \lor N = \text{นักฆ่า}$"

เนื่องจาก $R = L$ → "$R = T$" เป็นเท็จ → คำพูดของ $D$ = "$N = \text{นักฆ่า}$"

- ถ้า $D = T$ → $N = \text{นักฆ่า} = T$ → $A = L$
  - $A = L$ → "$R = \text{ผู้บงการ}$" เป็นเท็จ → $R \neq \text{ผู้บงการ}$
  - $N = T$ → "$A = T \lor D = \text{ผู้บงการ}$" → $D = \text{ผู้บงการ}$ แต่ $D = T$ และผู้บงการต้อง $L$ → ขัดแย้ง ❌

- **ถ้า $D = L$** → $N \neq \text{นักฆ่า}$ → $A = T, N = T$ ✓

### ขั้นที่ 4: หาบทบาท

**$A = T$:** คำพูด "$R = \text{ผู้บงการ}$" → จริง → $\boxed{R = \text{ผู้บงการ}}$

**$N = T$:** คำพูด "$A = T \lor D = \text{ผู้บงการ}$" → $A = T$ จริง ✓

**$D = L$:** คำพูด "$N = \text{นักฆ่า}$" → เท็จ → $N \neq \text{นักฆ่า}$

**$R = L$ (ผู้บงการ):** คำพูด "$R = T \lor N = \text{นักฆ่า}$" → เท็จ → $N \neq \text{นักฆ่า}$

ดังนั้น **$\boxed{A = \text{นักฆ่า}}$**

## ตารางสรุปคำตอบ

| คน | บทบาท | พูดจริง/โกหก |
|---|---|---|
| $G$ (กาลเวลา) | ผู้บริสุทธิ์ | โกหก |
| $R$ (รัตติกาล) | **ผู้บงการ** | **โกหก** |
| $D$ (ดีลักซ์) | ผู้บริสุทธิ์ | โกหก |
| $A$ (อัคนีเงา) | **นักฆ่า** | **จริง** |
| $N$ (เนตรทมิฬ) | ผู้บริสุทธิ์ | จริง |
