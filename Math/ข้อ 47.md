# ข้อ 47: การแก้ปัญหาด้วยเหรียญ Satarnmak Dollar (STM)

## ปัญหา
ต้องการซื้อสินค้าราคา 21 STM โดยใช้เหรียญ 3 STM, 5 STM และ 7 STM กี่วิธี (ไม่สนลำดับ)

## การแก้ไข

ตั้งสมการ:  
$3x + 5y + 7z = 21$ โดย $x, y, z \ge 0$ เป็นจำนวนเต็ม

### วิธีทำ
1. ลองค่า $z$ (เหรียญ 7 STM) ก่อน เพราะมีค่ามากที่สุด
2. กรณี $z = 0$: $3x + 5y = 21$
    - $y = 0 \Rightarrow x = 7$
    - $y = 3 \Rightarrow x = 2$
    - ได้ 2 วิธี
3. กรณี $z = 1$: $3x + 5y = 14$
    - $y = 1 \Rightarrow x = 3$
    - ได้ 1 วิธี
4. กรณี $z = 2$: $3x + 5y = 7$
    - ไม่มีคู่ $(x,y)$ ที่เป็นจำนวนเต็ม
5. กรณี $z = 3$: $3x + 5y = 0$
    - $x = 0, y = 0$
    - ได้ 1 วิธี

### ผลรวม
$2 + 1 + 1 = 4$ วิธี

## คำตอบ
**ก. 4**
