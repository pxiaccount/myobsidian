# วิเคราะห์โจทย์ข้อ 53

## สรุปโจทย์
มีผู้สร้าง (ผู้พูด) 4 คน แต่ละคนกล่าวอ้างจำนวนคนโกหก:

| คนพูด | ข้อความ |
|--------|---------|
| A | มีคนโกหก 1 คน |
| B | มีคนโกหก 2 คน |
| C | มีคนโกหก 3 คน |
| D | มีคนโกหก 4 คน |

**คำถาม**: ใครพูดความจริง?

## วิเคราะห์

ถ้าสมมติว่า **มีคนโกหก $k$ คน** และมีคนพูดความจริงเพียงคนเดียว (เพราะถ้ามีคนพูดความจริงมากกว่า 1 คน จะมีข้อความขัดแย้งกัน)

### ทดสอบแต่ละกรณี

**กรณี 1: A พูดจริง (มีคนโกหก 1 คน)**
- A พูดจริง = ไม่โกหก
- 1 ใน B, C, D ต้องเป็นคนโกหก
- แต่ถ้า B, C, D โกหกทั้งหมด = **มี 3 คนโกหก** (ไม่ใช่ 1) ❌ ขัดแย้ง

**กรณี 2: B พูดจริง (มีคนโกหก 2 คน)**
- B พูดจริง = ไม่โกหก
- 2 ใน A, C, D ต้องเป็นคนโกหก
- แต่ถ้า A, C, D โกหกทั้งหมด = **มี 3 คนโกหก** (ไม่ใช่ 2) ❌ ขัดแย้ง

**กรณี 3: C พูดจริง (มีคนโกหก 3 คน)**
- C พูดจริง = ไม่โกหก
- A, B, D ต้องเป็นคนโกหก
- ตรวจสอบ:
  - A บอกว่ามีคนโกหก 1 คน → จริงมี 3 คน → **A โกหก** ✓
  - B บอกว่ามีคนโกหก 2 คน → จริงมี 3 คน → **B โกหก** ✓
  - D บอกว่ามีคนโกหก 4 คน → จริงมี 3 คน → **D โกหก** ✓
  - C บอกว่ามีคนโกหก 3 คน → จริงมี 3 คน → **C พูดจริง** ✓

**กรณี 4: D พูดจริง (มีคนโกหก 4 คน)**
- D พูดจริง = ไม่โกหก
- แต่ถ้ามีคนโกหก 4 คน = ทุกคนต้องโกหก ซึ่งขัดแย้งกับ D ที่พูดจริง ❌

## คำตอบ

**ค. C** — C พูดความจริงว่ามีคนโกหก 3 คน (A, B, D)
