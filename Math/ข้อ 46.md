# เฉลยวิธีคิด: โจทย์การจัดเรียงลูกบอล (Combinatorics)

---

## 📌 โจทย์ (Problem Statement)
> **46. มีลูกบอลสีแดงและลูกบอลสีน้ำเงินอย่างละ 10 ลูก เลือกลูกบอล 10 ลูกมาเรียงแถว โดยมีเงื่อนไขว่า ลูกบอลสีแดงห้ามติดต่อกันเกิน 3 ลูก สามารถจัดแถวได้ทั้งหมดกี่วิธี**
> 
> * **ก.** 720
> * **ข.** 734
> * **ค.** 773
> * **ง.** 802

---

## 💡 การวิเคราะห์โจทย์ (Analysis)

1. **จำนวนและชนิดของสิ่งของ:**
   - มีลูกบอลสีแดง $R$ (อย่างน้อย 10 ลูก) และลูกบอลสีน้ำเงิน $B$ (อย่างน้อย 10 ลูก)
   - เราต้องการเลือกมาจัดเรียงเป็นแถวตรงความยาว **$n = 10$ ตำแหน่ง**
   - เนื่องจากมีสีละ 10 ลูก ซึ่งเพียงพอที่จะใช้สีใดสีหนึ่งล้วนได้ จึงถือว่าแต่ละตำแหน่งเลือกได้อิสระระหว่างสีแดง ($R$) หรือสีน้ำเงิน ($B$)

2. **เงื่อนไข:**
   - **ลูกบอลสีแดงห้ามเรียงติดกันเกิน 3 ลูก** หมายความว่า **ห้ามมี $RRRR$ (แดง 4 ลูกติดกันขึ้นไป)**
   - ความยาวของบล็อกสีแดงที่ติดต่อกันได้คือ $0, 1, 2,$ หรือ $3$ ลูก

---

## 🧮 วิธีคิดที่ 1: ใช้ความสัมพันธ์เวียนเกิด (Recurrence Relation)

ให้ $a_n$ แทนจำนวนวิธีเรียงลูกบอลความยาว $n$ ที่**ไม่มีสีแดงติดกันตั้งแต่ 4 ลูกขึ้นไป**

พิจารณาการลงท้ายของแถวความยาว $n$:
- **กรณีที่ 1: จบด้วยสีน้ำเงิน ($B$)**
  - แถวหน้า $n-1$ ตัวก่อนหน้าเป็นอะไรก็ได้ที่ถูกต้อง $\implies a_{n-1}$ วิธี
- **กรณีที่ 2: จบด้วยสีแดง 1 ตัว ($BR$)**
  - แถวหน้า $n-2$ ตัวก่อนหน้าเป็นอะไรก็ได้ที่ถูกต้อง $\implies a_{n-2}$ วิธี
- **กรณีที่ 3: จบด้วยสีแดง 2 ตัว ($BRR$)**
  - แถวหน้า $n-3$ ตัวก่อนหน้าเป็นอะไรก็ได้ที่ถูกต้อง $\implies a_{n-3}$ วิธี
- **กรณีที่ 4: จบด้วยสีแดง 3 ตัว ($BRRR$)**
  - แถวหน้า $n-4$ ตัวก่อนหน้าเป็นอะไรก็ได้ที่ถูกต้อง $\implies a_{n-4}$ วิธี

ดังนั้น รูปแบบความสัมพันธ์เวียนเกิดคือ (คล้ายลำดับ 4-step Fibonacci / Tetranacci):
$$a_n = a_{n-1} + a_{n-2} + a_{n-3} + a_{n-4} \quad (\text{สำหรับ } n \ge 4)$$

### กำหนดค่าเริ่มต้น (Base Cases):
* $n = 0$: $a_0 = 1$ (แถวว่าง)
* $n = 1$: $a_1 = 2$ ($R, B$)
* $n = 2$: $a_2 = 4$ ($RR, RB, BR, BB$)
* $n = 3$: $a_3 = 8$ (ได้ทุกแบบทั้ง $2^3 = 8$ แบบ เพราะยังไม่มีทางแดง 4 ตัวติด)

---

### คำนวณค่า $a_n$ จนถึง $n = 10$:

| $n$ | วิธีคิด | ค่า $a_n$ |
|:---:|:---|:---:|
| **0** | ค่าเริ่มต้น | **1** |
| **1** | ค่าเริ่มต้น | **2** |
| **2** | ค่าเริ่มต้น | **4** |
| **3** | ค่าเริ่มต้น | **8** |
| **4** | $a_3 + a_2 + a_1 + a_0 = 8 + 4 + 2 + 1$ | **15** |
| **5** | $a_4 + a_3 + a_2 + a_1 = 15 + 8 + 4 + 2$ | **29** |
| **6** | $a_5 + a_4 + a_3 + a_2 = 29 + 15 + 8 + 4$ | **56** |
| **7** | $a_6 + a_5 + a_4 + a_3 = 56 + 29 + 15 + 8$ | **108** |
| **8** | $a_7 + a_6 + a_5 + a_4 = 108 + 56 + 29 + 15$ | **208** |
| **9** | $a_8 + a_7 + a_6 + a_5 = 208 + 108 + 56 + 29$ | **401** |
| **10**| $a_9 + a_8 + a_7 + a_6 = 401 + 208 + 108 + 56$ | **773** |

---

## 🧮 วิธีคิดที่ 2: ใช้หลักการนับแบบตรงข้าม (Complementary Counting)

- **จำนวนวิธีทั้งหมดแบบไม่มีเงื่อนไข:** $2^{10} = 1024$ วิธี
- **จำนวนวิธีที่มีสีแดงติดกันตั้งแต่ 4 ลูกขึ้นไป ($RRRR$):** คำนวณได้ทั้งหมด $251$ วิธี

$$\text{จำนวนวิธีที่ถูกต้อง} = 1024 - 251 = 773 \text{ วิธี}$$
